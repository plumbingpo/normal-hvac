AC Installation Prevention Tips

Taking preventive measures can help you avoid costly heating and cooling problems down the road. Follow these tips from our experienced technicians:

  • Avoid huge thermostat setbacks, which force long, hard runs during the hottest hours
  • Address small issues early; a soft capacitor caught in April never becomes a July breakdown
  • Run a professional tune-up every spring to keep the charge and amp draws on spec
  • Give the condensate line a spring flush so a clog never shuts the system down
  • Replace filters on schedule from the very first month so the new system always breathes freely
  • Keep the outdoor unit rinsed clean and clear of vegetation on all sides
  • Leave all supply and return registers open so airflow stays balanced the way it was set up
